# Roadmap

Solo is under active development. This roadmap reflects current priorities and is subject to change based on community feedback.

## Now (Current Focus)

- [ ] **Stabilize Computer Use worker** — Improve vision-based GUI control accuracy
- [ ] **Write end-to-end tutorials** — Walk through common scenarios
- [ ] **Documentation improvements** — Fill gaps in installation and configuration guides
- [ ] **Community building** — Set up Discussions, respond to Issues

## Next (Short-term)

- [ ] **Simplify installation** — Create one-command setup script
- [ ] **Add Telegram gateway** — Alternative to WeChat messaging
- [ ] **Improve error handling** — Better error messages and recovery
- [ ] **Cross-machine validation** — Test on non-author machines
- [ ] **Docker Compose health checks** — Ensure all infrastructure services restart cleanly
- [ ] **Local vision model (Ollama)** — Integrate llava or similar for offline vision
- [ ] **Better Windows notifications** — Native toast notifications for approvals

## Later (Medium-term)

- [ ] **Mobile push notifications** — Approve tasks from phone
- [ ] **Task scheduling** — Scheduled/recurring tasks
- [ ] **Plugin system** — Third-party worker plugins
- [ ] **Multi-language support** — Non-Chinese WeChat accounts
- [ ] **Web dashboard** — Browser-based task monitoring
- [ ] **Model routing UI** — Visual configuration of model pipeline
- [ ] **Performance benchmarks** — Track agent response times

## Exploring

- [ ] **RAG integration** — Chat with your documents
- [ ] **Codex self-hosted** — Run coding agent without ChatGPT Plus
- [ ] **Voice output** — TTS for spoken responses
- [ ] **Clipboard automation** — Copy/paste and file transfer workflows
- [ ] **VSCode extension** — Developer integration

## Not Planned

- Multi-user/multi-tenant support
- Cloud-hosted version
- Kubernetes deployment
- Mobile app
- Enterprise SSO
- macOS/Linux native support
